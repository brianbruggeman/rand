# Rand

Yet another random number generator.  This time built on noise.

Taken from GDC17 talk: https://www.youtube.com/watch?v=LWFzPP8ZbdU


## Usage

To use, add this to your Cargo.toml:

```Cargo.toml
rand = { git = "https://github.com/brianbruggeman/rand", branch = "main" }
```

Alternatively, you may use `cargo add`:

```bash
cargo add rand --git https://github.com/brianbruggeman/rand
```
